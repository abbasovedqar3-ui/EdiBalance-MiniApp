# EdiBalance Mini App — комплект из 4 файлов

Файлы:
- `index.html` — главная страница.
- `style.css` — оформление, извлечённое из исходного V9.11 HTML.
- `app.js` — JavaScript-логика, извлечённая из исходного V9.11 HTML.
- `README.txt` — эта инструкция.

## Публикация на GitHub Pages
Загрузите все четыре файла в корень репозитория. Главный файл обязательно должен называться `index.html`.
В настройках GitHub Pages выберите ветку `main` и папку `/ (root)`.

## Важно
Это статический интерфейс-прототип V9.11. Он не становится полноценной Telegram Mini App с серверной логикой только от публикации на GitHub Pages. Telegram WebApp-аутентификация, API и Python backend должны быть настроены и размещены отдельно.
Не загружайте в публичный репозиторий токены, ключи, базу данных или личные данные.
