EdiBalance Mini App 2.0 — этап 2.1

Это готовый фронтенд-прототип интерфейса.
Файлы:
- index.html — экран приложения
- style.css — дизайн
- app.js — базовая интерактивность

Сейчас данные демонстрационные. На следующем этапе подключим реальную авторизацию Telegram,
данные EDI365, статистику и SQLite/сервер.

ВАЖНО:
Для открытия внутри Telegram нужен публичный HTTPS-адрес. Локальный file:// адрес для настоящего
Telegram Mini App не подходит.

Токен бота в этот проект не помещается.
